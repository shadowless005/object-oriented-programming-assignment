## Python Student Management

A Python assignment practicing object-oriented programming and common data types through a Student class.

## Features

- Create student objects with names, emails, and grades.

- Add grades, calculate averages, and display student information.

- Look up students by email using a dictionary.

- Display unique grades using a set.

- Convert grades to tuples and demonstrate immutability.

- Practice list operations using .pop(), indexing, and len().

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python3 ct_python_assignment.py
```

The program displays student information, grade averages, and data type demonstrations in the terminal. No external packages are required.
